INTRODUCCIÓN
El presente informe de prácticas pre-profesionales de la carrera de Ingeniería
de Sistemas tiene como objetivo documentar el desarrollo y la aplicación de conoci-
mientos técnicos especializados adquiridos durante la formación académica, mate-
rializados en la implementación de una solución tecnológica integral para el sector
educativo. Las actividades se desarrollaron enfocadas en la creación de un sistema
web completo para la gestión académica y administrativa de una institución de edu-
cación superior en el área odontológica.
Durante esta experiencia profesional, se ejecutó el análisis, diseño, desarro-
llo e implementación de una aplicación web full-stack denominada SIGA Odontolo-
gía (Sistema Integral de Gestión Académica), empleando el stack tecnológico MERN
(MongoDB, Express.js, React y Node.js). El sistema abarca módulos especializados
paralagestióndeprospectosacadémicos,publicacióndecontenidoinstitucional,ad-
ministración de eventos académicos, control de inscripciones estudiantiles, comuni-
cación bidireccional mediante formularios de contacto, y un panel administrativo cen-
tralizado con sistema de autenticación y autorización basado en roles diferenciados.
A través del proceso de levantamiento de requerimientos y análisis de nece-
sidades institucionales, se identificó la ausencia de una plataforma digital integrada
que permitiera centralizar los procesos académicos, administrativos y de comunica-
ción de la escuela de odontología. Esta problemática motivó el desarrollo de una
arquitectura cliente-servidor moderna con API RESTful, implementando patrones de
diseño escalables, buenas prácticas de seguridad mediante encriptación de contra-
señas con bcrypt y autenticación con JSON Web Tokens (JWT), validación robusta
deformulariosenclienteyservidor,yunainterfazdeusuarioresponsivedesarrollada
con Tailwind CSS que garantiza accesibilidad desde cualquier dispositivo.
El presente documento detalla el proceso completo de ingeniería de softwa-
re aplicado, desde el modelado de base de datos NoSQL con nueve colecciones
especializadas hasta la implementación de más de 40 endpoints API, destacando
la aplicación práctica de metodologías de desarrollo web modernas, arquitectura de
software, gestión de estado con Context API, manejo de autenticación y autorización
por roles, y la integración de funcionalidades avanzadas como upload de archivos
multimedia y sistema de gestión de eventos con control de asistencias. Este informe
evidenciaelimpactodelaformaciónacadémicaeningenieríadesistemasparalage-

2.1. Extreme Programming (XP)
ExtremeProgramming(XP)esunametodologíaágilcentradaenlaen-
trega temprana y frecuente de software funcional, la simplicidad del diseño y
laadaptacióncontinuaalcambio.Proponevalores(comunicación,simplicidad,
retroalimentación,corajeyrespeto)yprácticascomoprogramaciónenpareja,
propiedad colectiva del código, refactorización continua, integración/entrega
continuas (CI/CD) y desarrollo guiado por pruebas (TDD) (Beck, 2004). XP
reduce el riesgo al construir el producto en iteraciones cortas con historias
de usuario priorizadas y criterios de aceptación verificables. Para un sistema
de gestión académica como SIGA Odontología, XP facilita validar primero los

institucionales) y ajustar reglas de negocio conforme aparecen nuevos reque-
rimientos; su énfasis en pruebas automatizadas y refactorización mejora la
mantenibilidad a largo plazo (Beck, 2004).

2.9.7. Autenticación: JWT (JSON Web Tokens)
JSON Web Tokens (JWT) es un estándar abierto (RFC 7519)

tokens compactos y auto-contenidos firmados digitalmente. Los JWT
constan de tres partes codificadas en Base64URL: header (tipo de to-
ken y algoritmo), payload (claims con información del usuario), y sig-
nature (verificación de integridad). En SIGA Odontología, JWT imple-
mentaautenticaciónstatelesssinnecesidaddealmacenarsesionesen
servidor: tras login exitoso, el servidor genera un token con payload
conteniendoiddeusuario,emailyrol,firmadoconsecretoconfigurado
envariablesdeentorno.Eltokentieneduraciónde30díasysealmace-
na en localStorage del cliente. Cada petición protegida incluye el token
en header Authorization: Bearer, y middleware backend verifica firma y
expiración antes de permitir acceso (Jones et al., 2015).
2.9.8. Encriptación: bcryptjs
bcrypt es un algoritmo de hashing de contraseñas basado en
el cifrado Blowfish, diseñado específicamente para ser computacional-
mente costoso y resistente a ataques de fuerza bruta mediante un fac-
tordetrabajoconfigurable(costfactor).bcryptincorporasaltautomático
único por contraseña, previniendo ataques de tabla rainbow y garanti-
zando que contraseñas idénticas generen hashes diferentes (Provos
Mazières, 1999). En SIGA Odontología, bcryptjs (implementación Ja-
vaScript pura) hashea todas las contraseñas antes de almacenarlas
en MongoDB con cost factor de 10 rondas, proporciona funciones de
comparación seguras para validar credenciales durante login, y nunca
almacena ni transmite contraseñas en texto plano.

Odontología de la Universidad Privada de Tacna, mejorando significa-
tivamente la eficiencia operativa mediante digitalización de procesos,
facilitando el acceso a información actualizada para la comunidad uni-
versitariayfortaleciendolacapacidaddeanálisisinstitucionalmediante
generación de reportes estadísticos basados en datos consolidados.

administrativos de la Escuela Profesional de Odontología. Implementa
una arquitectura de cliente-servidor con API RESTful que garantiza

destacado,automatizacióndelprocesodeinscripciónmediantefor-

Sistema Operativo:
Conelfindeasegurarlacompatibilidadyelrendimientoeficien-

la Escuela Profesional de Odontología, se ha considerado la compati-
bilidad con varios sistemas operativos, entre los cuales se encuentra
Windows 10/11 para estaciones de trabajo administrativas y Ubuntu
Server 20.04 LTS o superior para el servidor de aplicación y proxy in-
verso mediante Nginx.
Lenguaje de Desarrollo:
Ellenguajedeprogramaciónseleccionadodebecumplirconcri-
terioscomolacapacidadparamanejarmúltiplesconexionesconcurren-
tes, facilidad en el desarrollo y mantenimiento, así como estabilidad y
robustez. Por ello, se ha decidido utilizar TypeScript y JavaScript, con
Node.js y Express para el backend y React con Vite para el frontend.
Estacombinacióntecnológicapermitedesarrolloágil,ciclosdeentrega
cortosyfacilitalaintegraciónmedianteAPIRESTconotrasplataformas
institucionales cuando sea necesario.
Laeleccióndeestastecnologíasrespondeasucapacidadpara
operar tanto de forma integrada con sistemas existentes en la univer-
sidad como de manera independiente cuando se requiera. El sistema
hasidodiseñadoconarquitecturamodularquefacilitasumantenimien-
to evolutivo y permite escalabilidad horizontal mediante contenedores
Docker, ofreciendo así mayor flexibilidad en su implementación y ope-
ración continua.
Sistema Gestor de Base de Datos:
La selección del sistema gestor de bases de datos es funda-
mentalparagarantizarlaflexibilidaddeesquema,escalabilidadyrendi-
miento del sistema. En este contexto, se ha decidido utilizar MongoDB
en su versión 6.0 o superior, aprovechando servicios gestionados ti-
po MongoDB Atlas que ofrecen respaldos automatizados, réplicas y
escalabilidad sin intervención manual. El modelado de datos se reali-
za mediante Mongoose, lo que proporciona validaciones de esquema,
consistenciareferencialyfacilitaelmantenimientodelcódigodeacceso
a datos.

CONCLUSIONES
El presente informe de prácticas pre-profesionales evidencia que la implementación
del Sistema Integral de Gestión Académica (SIGA) para la Escuela Profesional de
Odontología de la Universidad Privada de Tacna constituye una solución efectiva pa-
racentralizaryautomatizarprocesosacadémicos,administrativosydecomunicación
institucional que previamente se ejecutaban de manera manual y dispersa. El sis-
tema desarrollado mediante arquitectura React-Node.js-MongoDB, desplegado con
contenedores Docker y servidor Nginx, demostró ser técnicamente viable, operativa-
mente eficiente y económicamente rentable, mejorando significativamente la calidad
